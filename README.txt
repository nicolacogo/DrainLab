DrainLab v0.2.1 - quick start
1. Unzip the folder.
2. Double-click index.html (Chrome/Edge, internet connection needed).
   If any map or search doesn't load, run it via a local server instead:
   open a terminal in the folder, type:  python -m http.server 8000
   then go to http://localhost:8000
3. Layers (top right): Streets / Satellite (with labels) / Topographic (contours).
4. Search a postcode or place, draw a polygon (top left tool), choose rainfall mode, enter C.
